Cloud Scheduler fans out one Pub/Sub message per site, and a Cloud Run Job crawls that site with Playwright. The diff itself is plain code the model cannot reach around, because an LLM asked to eyeball two host lists will eventually miss one, and a missed marketing pixel is the failure this whole thing exists to prevent. Two Gemini agents on Vertex do the judgement: is this real drift, and what does the policy now have to say. Then the notifier opens the ticket and sends the mail.
